Methods Writer

Fill in what you did, and get a methods section and a channel metadata table for a multiplex tissue imaging study. Fields follow the MITI reporting guidelines, so the details reviewers and data repositories ask for are less likely to be left out.

Antibodies and channels

One row per channel, including the nuclear stain. The channel name should match the name in your image file. Labels such as 165Ho are written to the metal isotope columns of the CSV; other labels go to the fluorophore column.

Methods text

Built only from what you entered; empty fields are left out. Read it and edit it before use.

MITI fields still empty

The fields on this page that MITI marks required or recommended. MITI also covers clinical, file and image-header fields that this page does not ask for; your repository's template collects those.
