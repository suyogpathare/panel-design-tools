MITI Checker

Check the metadata tables for a multiplex tissue imaging dataset before you submit them. Load a filled-in CSV or TSV and see which required fields are empty, which values are outside MITI's lists, and which values have the wrong type.

Check files

One table per file, with a header row. The checker guesses which MITI table each file is from its column names; change it if the guess is wrong. Row numbers count the header as row 1, as in a spreadsheet. Files are read in this browser and nothing is sent anywhere.

Blank templates

A CSV with every MITI column for one table, in MITI's order. Required columns come first.

    What is checked
    • Columns. Every required column of the table is present. Column names are matched ignoring case, spaces and punctuation, so "catalog_number" will not match "Catalog #" but "catalog #" will.
    • Required values. No required cell is empty. A cell reading "n/a" or "not applicable" is listed as a note, not an error. Conditional requirements in MITI (for example, PhysicalSizeZ when the image is a Z-stack) are applied row by row.
    • Allowed values. Where MITI gives a list, each value is in it. A difference only in capitals is a warning; anything else is an error, with the closest listed value suggested.
    • Types. Whole numbers, numbers, true/false, dates (YYYY-MM-DD) and RRIDs (RRID:AB_123456) have the right form, and numbers respect MITI's minimums.
    • Labels (channel table). MITI lists the fluorophore, metal isotope and oligo barcode columns as required, but a channel carries one kind of label. Each channel needs one complete label: a fluorophore, or a metal element with its mass, or both barcode strands.
    • Nuclear stains (channel table). Rows for DAPI, Hoechst, DRAQ5, SYTO and iridium intercalators are not antibodies, so antibody name, clone and RRID are not required for them.
    • Consistency (channel table). Channel IDs and channel names are unique, and one RRID is not used for two different targets.

    The checker does not open image files, so it cannot confirm that channel IDs and names match your OME-TIFF header. Check those against the file.

    Attribute names, types, requirements and value lists come from the MITI reporting guidelines: Schapiro D, Yapp C, Sokolov A, et al. MITI minimum information guidelines for highly multiplexed tissue images. Nature Methods 2022;19:262–267.
