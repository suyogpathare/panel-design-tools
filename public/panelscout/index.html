PanelScout

Paste a gene list to see how much of it each imaging spatial transcriptomics panel covers, which genes each panel is missing, and which genes no panel has. Load the panels you want to compare from the vendors' own files; everything runs in your browser, and nothing you load or paste is uploaded. Common names such as PD-L1 or Ki-67 are matched to gene symbols.

Panels to compare

PanelScout does not host vendor panel lists. Download the gene list files you want to compare from each vendor, then load them here:

  1. 10x Genomics Xenium: on the pre-designed Xenium v1 panels or Xenium Prime 5K page, download each panel's gene list (JSON). A custom panel's JSON from Xenium Panel Designer works too.
  2. Bruker CosMx: from each panel's gene list page at Bruker Spatial Biology (for example the Human 6K Discovery gene list), download the Excel file.
  3. Any other panel: a CSV or text file with one gene per line (first column of a CSV).
or drop files here. Loaded panels are kept in this browser only.
